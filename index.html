How the signal works

  1. Color bias counts pixels that newly turned green or red since the previous sample (new bubble prints), weighted toward recent samples in the window. (G − R) / (G + R) gives a value from −1 to +1.
  2. Vertical drift takes the average height of new bubbles in the leading-edge zone on each sample and fits a regression line across the window. Bubbles printing higher means price is rising, which counts as bullish.
  3. Score is the weighted blend of the two, from −100 to +100. BULLISH or BEARISH turns on when |score| exceeds the enter threshold for the set number of confirm samples, and stays on until |score| falls below the exit threshold. This hysteresis stops flicker.
  4. Momentum compares the current score with the score at the lookback time. It shows whether the move is building or fading before the label changes.
